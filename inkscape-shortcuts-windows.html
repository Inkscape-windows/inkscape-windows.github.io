Inkscape Keyboard Shortcuts for Windows

Complete keyboard shortcuts reference for Inkscape on Windows. Essential shortcuts for tools, path editing, objects, text and file operations — plus how to customise and create your own shortcuts.

Customise shortcuts

All Inkscape shortcuts can be changed: Edit → Preferences → Interface → Keyboard shortcuts. Click any action, press your new key combination and save. You can export/import shortcut profiles as XML files — useful for sharing with team members.
