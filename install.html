How to Install Inkscape on Windows 11/10

This short guide walks you through installing Inkscape 1.4.2 on Windows using the official MSI (x64). If you haven't downloaded the installer yet, use the button below.

TL;DR (Quick install)

  1. 1 Download the official MSI for Windows x64.
  2. 2 Close other apps and run the installer.
  3. 3 Choose destination folder and proceed.
  4. 4 Finish setup and launch Inkscape from Start.

Detailed steps

  1. 1
    Get the installer

    Use the MSI linked on this page. It targets 64‑bit Windows 10/11. If you're on a managed/work PC, you may need administrator rights.

  2. 2
    Close other apps

    Save your work and close design apps to avoid file locks or font cache conflicts during installation.

  3. 3
    Run the MSI

    Double‑click the MSI and follow the setup wizard. Approve the User Account Control prompt if shown.

  4. 4
    Choose destination and options

    Pick an install folder and optional components (if offered). Default settings work well for most users.

  5. 5
    Finish and launch

    Click Finish. Open Inkscape from the Start menu. On first run, you can customize UI scaling and theme in Preferences.

Verify authenticity

  • The file is served from an official Inkscape mirror (media.inkscape.org).
  • Keep Windows SmartScreen enabled during installation.
  • Prefer downloading via HTTPS and avoid re‑hosted installers.

Common installation issues

  • Installer won’t start: right‑click the MSI → Properties → Unblock (if present), then try again.
  • Permission errors: run the MSI as administrator.
  • Missing fonts in Inkscape after install: rebuild Windows font cache or restart; see Troubleshooting.
  • Slow first launch: allow initial font and extension scan to finish; subsequent launches are faster.
