After downloading — installation steps

1

Run as Administrator

Right-click the downloaded .msi → Run as administrator. If Windows SmartScreen appears, click More info → Run anyway (the file is signed).

2

Follow the installer wizard

Default installation path (C:\Program Files\Inkscape) is fine for most users. Leave all components ticked.

3

First launch may be slow

Inkscape initialises fonts and extensions on first run — this can take 15–30 seconds. Subsequent launches are faster.

4

Check system requirements

See system requirements if Inkscape is slow or crashing. A GPU with OpenGL 2.0 is strongly recommended for smooth rendering.

About Inkscape for Windows

Inkscape is a professional-grade free and open source vector graphics editor. It uses the W3C standard SVG format as its native file format and is used by graphic designers, illustrators, web designers and hobbyists worldwide. Common uses include logo design, icon creation, illustration, technical diagrams, typography and web graphics.

On Windows, Inkscape installs as a standard desktop application via an MSI package. It runs on Windows 10 version 1903 and later and Windows 11 (both 64-bit). The application supports GPU-accelerated canvas rendering via OpenGL, high-DPI display scaling, multi-monitor setups and full Windows accessibility APIs.

Inkscape 1.4.4 is the latest stable release. It includes improved performance, a refreshed filter gallery, enhanced font browser and better accessibility support compared to earlier versions.
